# Credit Builder Flow - POE Project

## Project Overview
Credit Builder Flow is a specialized service designed to assist South African vehicle dealerships by recovering and rehabilitating declined finance leads. This repository contains the front-end website source code developed as part of a Summative Assessment Portfolio of Evidence (POE).

## Business Objectives
* Establish a "circular referral" system that bridges the gap for customers rejected for vehicle finance.
* Rehabilitate client credit profiles and route them back to the original dealership.
* Present a professional, trustworthy online presence to attract both B2B dealership partners and B2C clients.

## Technologies Used
* **HTML5:** Semantic structure, accessible navigation, and content layout (Part 1).
* **Integrations:** Embedded Google Maps (Location) and Tally Forms (Vehicle Finance Pre-Approval Audit).
* **CSS3:** Visual styling and responsive design *(To be implemented in Part 2)*.

## Website Structure
* `index.html` - The core business case and brand introduction.
* `services.html` - Detailed breakdown of Credit Packages and F&I Partner Programs.
* `about.html` - The company mission and background.
* `faq.html` - Frequently asked questions regarding credit repair.
* `contact.html` - Direct contact details, interactive map, and the lead generation form.
* `/images` - Directory containing logo and layout assets.
